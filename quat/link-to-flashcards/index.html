Turn an article or a link into flashcards

Some of what you study never goes through your keyboard at all — a guideline page, a documentation chapter, an article someone sent you. It gets read once, agreed with, and forgotten.

Quat takes the link instead. It fetches the page, reads it, summarises what matters into a note, and turns the note into flashcards that come back on a spaced-repetition schedule.

The steps

  1. Open Quat, go to the Capture tab, and choose Link.
  2. Paste the URL.
  3. Tell it what to focus on, if you want — "key concepts and examples", or whatever the page should be reduced to. You can add tags at the same step.
  4. Quat fetches the page and reads it. It reads the actual page, so it cannot invent what is not there — if a page only shows its content behind a login, Quat can only read what a visitor without one would see.
  5. Check the note it wrote, then let it build the cards. Each carries its origin — LINK · AUG 05 · SEPSIS BUNDL — so any card can point you back to its source.
  6. Review on schedule. Sessions end when the day's cards are done.

Worth knowing before you paste

  • The focus line is the difference between "summarise this page" and "pull out what I need from this page". One phrase is enough.
  • Long reference pages card better than homepages — paste the chapter, not the site.
  • Because every card is stamped, a deck built from five different sources stays auditable: you always know which claim came from where.

What it costs
